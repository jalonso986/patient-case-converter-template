# Patient Case Converter Template

Template reutilizable para generar Virtual Cards de pacientes dentales.

## Objetivo

Transformar automáticamente:

- Cotizaciones
- Casos multidisciplinares
- Planes de tratamiento

en una experiencia visual premium optimizada para WhatsApp.

## Arquitectura

### index.html
Frontend principal.

### data.js
Datos estructurados del paciente y tratamientos.

### assets/
Imágenes generales:
- Logo
- Foto paciente
- Odontograma
- Timeline
- Iconos

### explanations/
Infografías explicativas por tratamiento.

## Próximo paso

PDF / Imagen de presupuesto
→ extracción IA
→ JSON estructurado
→ generación automática de Virtual Card
